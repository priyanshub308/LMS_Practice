-------- To pull the repo from the github
git clone https://github.com/priyanshub308/LMS_Practice.git 


----- To check the current branch
git branch

----- to check the current status of modified files
git status

---- To add the files in the branch
git add .

---- After adding need to commit
git commit -m "Added gitcommands.txt and powershell.txt"

---- push the code to desired branch
git push origin learning-docs-or-commands

---- pull the current code in the branch
git pull origin learning-docs-or-commands
